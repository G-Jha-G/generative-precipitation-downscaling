# Generative Precipitation Downscaling

Code and reproducibility resources for generative deep-learning-based high-ratio precipitation downscaling using Flow Matching and diffusion models.

The framework is evaluated over India with a focus on fine-scale spatial structure, precipitation distributions, extremes, temporal behaviour, monsoon phases, and probabilistic prediction.

## Environment

The required Python/Conda environment is provided in:

`environment.yml`

Create the environment with:

```bash
conda env create -f environment.yml
conda activate pytorch_env
